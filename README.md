# HidratateApp

HidratateApp permite registrar cuánta agua tomamos y llevar un seguimiento diario de nuestro consumo.

## ¿Qué se puede hacer?

- Registrar consumos de agua en mililitros.
- Ver el progreso hacia una meta diaria.
- Consultar el historial de los últimos días y elegir una fecha.
- Cambiar el nombre, la meta diaria y los recordatorios.
- Administrar usuarios con una cuenta de administrador.

## Cómo iniciar el proyecto

Necesitás tener instalado Node.js. Desde la carpeta del proyecto, ejecutá:

```bash
npm install
npm run dev
```

Después, abrí en el navegador la dirección que muestra la terminal (normalmente `http://localhost:5173`).

## Cuentas de ejemplo

Podés usar los botones de la pantalla de ingreso o completar los datos manualmente:

| Tipo de cuenta | Correo | Contraseña |
| --- | --- | --- |
| Administrador | `admin@hidratate.app` | `Admin123!` |
| Usuario | `usuario@hidratate.app` | `Usuario123!` |

Son cuentas de prueba para el proyecto. No uses contraseñas personales.

## Tecnologías

El proyecto está hecho con React y Vite. Los datos se guardan en el almacenamiento local del navegador.
